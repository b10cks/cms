# Code of Conduct

We expect everyone in this community to be kind, patient, and constructive. Harassment, gatekeeping, and dismissiveness have no place here. Treat people the way you'd want to be treated on a bad day.

This applies everywhere the project lives: GitHub issues, pull requests, discussions, and [Discord](https://discord.gg/mdcDktFFcp).

## In practice

- Assume good faith — most mistakes are honest ones.
- Critique code and ideas, not people.
- Welcome newcomers; everyone's question was once a beginner's question.
- Disagree without being disagreeable. If a thread gets heated, step away before replying.

## Unacceptable behavior

Harassment, personal attacks, discriminatory remarks, sexualized language or imagery, doxxing, sustained disruption, and any conduct that a reasonable person would consider inappropriate in a professional setting.

## Reporting and enforcement

Report violations to [hello@b10cks.com](mailto:hello@b10cks.com). Reports are handled confidentially. Maintainers may remove comments, close threads, or ban contributors whose behavior violates this code — proportionate to the violation, with escalating consequences for repeat offenses.
