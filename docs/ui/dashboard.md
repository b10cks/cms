# Dashboard & Navigation

## Signing in and picking a space

After signing in (email/password with optional two-factor authentication, or a social login provider if configured), you land on the **spaces overview** — every space you have access to, directly or through a team. Selecting a space opens it; the URL always contains the space, so deep links keep working.

## Space navigation

Inside a space, the sidebar is the main navigation:

| Item | What it is |
| --- | --- |
| **Home** | The space dashboard |
| **Content** | The content tree and editor — where most daily work happens ([guide](content.md)) |
| **Canvas** | The visual whiteboard-style content editor ([guide](canvas.md)) |
| **Blocks** | The block library: content types and their schemas ([guide](blocks.md)) |
| **Assets** | The asset manager ([guide](assets.md)) |
| **Data sets** | Data sources and their entries ([guide](data-sources.md)) |
| **Icons** | The space's icon registry ([guide](icons.md)) |
| **Redirects** | URL redirect management ([guide](redirects.md)) |
| **Releases** | Bundled, atomic publishing ([guide](releases.md)) |
| **Automations** | Trigger → action workflows ([guide](automations.md)) |
| **Audit Log** | Every change in the space, filterable ([guide](audit-logs.md)) |
| **Settings** | Space configuration ([guide](settings.md)) |

The sidebar can be toggled between compact and extended.

## Command palette

Press <kbd>⌘K</kbd> / <kbd>Ctrl K</kbd> to open the command palette — jump to content, blocks, assets, or settings pages, and run common actions without leaving the keyboard.

## Notifications

The bell icon collects in-app notifications — mentions in comments, finished background jobs (imports, backups, exports), and workflow events. Notifications can also arrive by email depending on their type. **Mark all read** clears the counter.

## Presence & real-time updates

The app is real-time throughout: lists refresh when someone else changes data, and content editors show who else is currently viewing or editing the same entry (avatars with live cursors in the editor). No manual refreshing needed.
